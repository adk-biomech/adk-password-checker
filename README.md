# ADK Password Strength Checker

A Python-based command-line tool that evaluates password strength and provides actionable feedback.

## Features
- Checks password length
- Detects uppercase and lowercase letters
- Detects numbers
- Detects special characters
- Returns strength level (Weak / Medium / Strong)
- Suggests improvements

## Tech Stack
- Python
- Regex (re module)

## Usage
Run the program:

```bash
python main.py
